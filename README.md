##  Desktop Controls

| Key           | Action           |
| ------------- | ---------------- |
| **Space / ↑** | Jump             |
| **↓ Arrow**   | Duck             |
| **ESC**       | Pause / Settings |

###  Mobile

| Gesture          | Action |
| ---------------- | ------ |
| Tap Upper Screen | Jump   |
| Tap Lower Screen | Duck   |

## 📂 Project Structure

```text
Clawd-Runner-Cityscapes/
│
├── index.html          # Main Game UI
├── styles.css          # Styling & Themes
│
├── assets/             # Logo, Poster & Images
│   ├── gamelogo.png
│   ├── poster.png
│   ├── 1.png
│   └── 2.png
│
└── js/
    ├── state.js        # Game State
    ├── entities.js     # Player & Obstacles
    ├── renderer.js     # Canvas Rendering
    ├── engine.js       # Game Engine
    └── controller.js   # Keyboard & Touch Controls
```
